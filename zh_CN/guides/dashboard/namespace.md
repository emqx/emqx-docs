# 命名空间

命名空间监控页面用于展示 EMQX 中与命名空间相关的消息流量与规则执行等关键指标，帮助用户了解系统整体或不同命名空间维度下的业务负载情况。该页面主要用于多租户场景下的运行监控与使用情况分析。


## 命名空间选择

页面顶部提供命名空间选择下拉框，用于切换指标的统计范围。

- 当前版本中仅支持**全局**视图，用于展示所有命名空间的聚合指标数据。
- 当系统中存在可区分的命名空间时，将支持在此处选择具体命名空间进行查看。

## 指标说明

下表列出了命名空间监控页面中展示的各项指标及其说明。

| 指标名称     | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| 已接收消息数 | EMQX 接收到的消息总数，当前为所有命名空间的聚合值。          |
| 已发送消息数 | EMQX 向客户端成功投递的消息总数，当前为所有命名空间的聚合值。 |
| 总会话数     | 当前系统中的 MQTT 会话总数。                                 |
| 动作执行总数 | 由规则或 Flow 触发并成功执行的动作总次数。                   |

## 使用说明

- 命名空间监控页面仅用于展示统计指标，不提供配置或管理操作。
- 页面中的指标均为累积值，自节点或集群启动后持续统计。
- 该页面适用于多租户环境下的运行状态观测与使用情况分析。
