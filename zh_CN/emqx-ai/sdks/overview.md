# MCP over MQTT 和多媒体服务 SDK

EMQX 提供了多种平台和编程语言的 SDK，帮助开发者快速集成 MCP over MQTT 和多媒体服务器的功能。这些 SDK 封装了底层的通信细节，使开发者能够专注于业务逻辑的实现。

## 多媒体服务客户端代码示例

EMQX 提供了基于 WebRTC 和 MQTT 的客户端示例，演示如何与多媒体服务器交互，实现音视频通话、语音识别（ASR）和文本转语音（TTS）等功能。  

开发者可以直接使用这些示例作为参考，将多媒体 AI 能力快速集成到 Web 应用或设备中。

- [TypeScript WebRTC 示例](./webrtc-typescript.md)
