# EMQX 6.1 已知问题

## 6.1.1

| 始于版本 | 问题描述                                                     | 解决方法                                                     | 状态 |
| -------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ---- |
| 5.8.0    | **启用持久化存储时，核心-复制节点集群可能无法完成启动**<br />在由核心节点和复制节点组成的集群初始化过程中，持久化存储元数据可能在各节点间出现不一致，导致相关功能（会话持久化、消息队列、消息流）出现部分不可用。这可能影响新建集群和从 EMQX 5.x 升级的集群，特别是在 `n_sites` 配置值大于 1 的情况下。典型表现为持续输出以下告警：<br />`msg: dsrepl_optimistic_leader_fail, reason: {init_failed,{error,recoverable,{fsm_needs_upgrade,0}}}` | 逐个停止并重启复制节点。 | - |
