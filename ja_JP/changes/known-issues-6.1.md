# EMQX 6.1  既知の問題

## 6.1.1

| バージョン | 問題                                                      | 回避策                                                    | ステータス |
| ------------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------ |
| 5.8.0         | **Durable Storage が有効な場合、コア-レプリカントクラスターの起動が完了しない可能性がある**<br />コアノードとレプリカントノードで構成されるクラスターの初期化中に、Durable Storage（DS）メタデータがノード間で整合性を失い、関連する機能（Durable Sessions、Queues、Streams）が部分的に利用できなくなる場合があります。これは新しいクラスターと EMQX 5.x からアップグレードしたクラスターの両方に影響し、`n_sites` が 1 より大きい値に設定されている場合に特に発生します。次のような警告が繰り返し出力されるのが典型的な症状です：<br />`msg: dsrepl_optimistic_leader_fail, reason: {init_failed,{error,recoverable,{fsm_needs_upgrade,0}}}` | レプリカントノードを1つずつ停止して再起動してください。 | - |
