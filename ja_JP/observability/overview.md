# ログとオブザーバビリティ

EMQX は、システムの監視、管理、および診断を支援する一連のオブザーバビリティ関連機能を提供しています。これらの機能はすべて、ダッシュボードの以下のメニュー項目からアクセスおよび設定できます。

**監視**:

- [メトリクス](./metrics-and-stats.md)

  EMQX はメトリクス監視機能を提供しており、運用担当者はこれを基に現在のサービ ス状況を監視し、システムの不具合をトラブルシューティングできます。ユーザーは EMQX ダッシュボード、HTTP API、およびシステムトピックを使ってメトリクスデータを追跡可能です。

- [アラーム](./alarms.md)

  EMQX は CPU 使用率、システムおよびプロセスメモリ使用率、プロセス数、ルールエンジンのリソース状況、クラスターのパーティションおよび回復状況を監視する組み込みの監視・アラーム機能を備えており、システムの不具合発生時にアラームを発報します。

**管理**:

- [ログ](./log.md)

  ログはトラブルシューティングやシステムパフォーマンス最適化のための信頼できる情報源です。EMQX のログからアクセス状況、操作履歴、ネットワーク問題の記録を確認できます。

- [Prometheus との統合](./prometheus.md)

  [Prometheus](https://prometheus.io/) は SoundCloud がオープンソースで提供する監視ソリューションで、多次元データモデルのサポート、柔軟なクエリ言語、強力なアラーム管理を特徴としています。EMQX は Prometheus と統合し、システムメトリクスの収集や `pushgateway` へのメトリクスプッシュをサポートします。

- [ブローカーのヘルス指標](./broker-health-indicators.md)

  EMQX ブローカーの監視に役立つ Prometheus メトリクスをシステム、ブローカー、認証／認可、データ統合ごとに厳選してまとめたリファレンスです。Prometheus 統合ガイドと併せて使用し、どのメトリクスをスクレイプし、アラート設定やグラフ化に活用するかを判断できます。

- [Datadog との統合](./datadog.md)

  [Datadog](https://www.datadoghq.com/) はアプリケーションの統合的かつリアルタイムなオブザーバビリティとセキュリティソリューションを提供するプラットフォームです。EMQX は Datadog と統合し、EMQX の稼働状況の把握、システムパフォーマンス問題の監視・トラブルシューティング、Datadog コンソール上での EMQX メトリクスの閲覧を支援します。

**診断**:

- [トピックメトリクス](./topic-metrics.md)

  EMQX はトピック監視機能（トピックメトリクス）を提供しており、特定のトピックに対して送受信されたメッセージ数やレートなどのメトリクスをカウントできます。この機能はダッシュボードの **診断** -> **トピックメトリクス** ページから閲覧・利用でき、HTTP API からも設定可能です。

- [スローサブスクリプション](./slow-subscribers-statistics.md)

  通常、EMQX はメッセージの送信をミリ秒単位で完了しますが、主にネットワークの影響を受けます。しかしクライアント側でサブスクリプションメッセージのレイテンシが非常に高いケースがあります。この問題を解決するために、EMQX はスローサブスクリプション機能を提供しています。

- [ログトレース](./tracer.md)

  EMQX 5.x ではログトレース機能が追加され、特定のクライアントID、トピック、またはIPに対してリアルタイムでデバッグレベルのログ出力を有効化できます。
