# モニタリング

モニタリングは、稼働中のEMQXクラスターの情報やデータを表示および管理するために使用されます。ダッシュボードの左側ナビゲーションメニューの**モニタリング**を展開すると、以下のサブメニューが表示されます。

- **[クラスター概要](./dashboard.md)**：EMQXクラスターの接続、サブスクリプション、ノード情報、システムメトリクスを一元的に表示します。
- **[クライアント](./connections/connections.md)**：クライアントの接続およびセッションに関する詳細情報とメトリクスを提供します。
- **[サブスクリプション](./subscriptions/overview.md)**：EMQXに接続しているクライアントのサブスクリプションおよびトピックの基本情報を表示します。
- **[ネームスペース](./namespace.md)**：メッセージトラフィックやルール実行のメトリクスを含むネームスペースに関連する統計情報を表示します。
- **[保持メッセージ](./retained.md)**：システム内に現在保持されているすべての保持メッセージを表示します。
- **[遅延パブリッシュ](./delay-pub.md)**：遅延パブリッシュ用のメッセージ情報を表示し、遅延パブリッシュ機能の設定を行います。
- **[アラーム](./alarm_dashboard.md)**：現在および過去のシステムアラーム情報を表示します。
