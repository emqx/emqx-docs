# Smart Data Hub

ダッシュボードのSmart Data Hubセクションでは、スキーマ、スキーマ検証ルール、およびメッセージ変換ルールの作成と設定が可能です。

- [**スキーマレジストリ**](../data-integration/schema-registry.md)：スキーマ検証やSQLルールで使用する内部または外部のスキーマを作成できます。ダッシュボードでのスキーマ作成方法については、[スキーマレジストリの例 - Avro](../data-integration/schema-registry-example-avro.md) または [スキーマレジストリの例 - Protobuf](../data-integration/schema-registry-example-protobuf.md) を参照してください。
- **スキーマ検証**：特定のトピックにパブリッシュされるデータがあらかじめ定義されたデータ形式に準拠していることを保証するために、検証ルールを使用します。検証ルールの作成方法については、[ダッシュボードでのスキーマ検証の設定](../data-integration/schema-validation.md#configure-schema-validation-in-dashboard) をご覧ください。
- **メッセージ変換**：システムを流れるデータに適応させるための変換式を定義します。変換の作成方法については、[ダッシュボードでのメッセージ変換の設定](../data-integration/message-transformation.md#configure-message-transformation-in-dashboard) を参照してください。
