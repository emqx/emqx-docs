# データ統合

ダッシュボードのデータ統合セクションでは、ルールの作成、さまざまなデータシステムとのデータ統合、スキーマ検証、メッセージ変換の機能を提供しています。また、設定の編集や機能の統計情報の閲覧などの管理操作も行えます。サブセクションは以下の通りです。

- **Webhook**：HTTPサービスと統合したいが、データ処理にルールを使用する必要がないユーザー向けに、よりシンプルで使いやすい作成および設定体験を提供します。詳細なステップバイステップガイドは[Webhook](../../develop/data-integration/webhook.md)をご参照ください。
- **Flowデザイナー**：データ処理および統合を視覚的に確認・管理できる強力なツールです。詳細な紹介は[Flowデザイナー](../../develop/flow-designer/introduction.md)をご覧ください。
- [**ルール**](./rules.md)：ルールの作成、ルールのテスト、ルールへのアクション追加、ルール実行統計の閲覧に関するすべての機能を提供します。
- **コネクター**：データ統合の不可欠なコンポーネントであり、外部データシステムとの接続に使用されます。コネクターの作成および管理方法については[コネクター](../../develop/data-integration/connector.md)をご参照ください。
