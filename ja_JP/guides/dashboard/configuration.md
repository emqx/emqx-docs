# 管理

EMQXは、システム構成の最適化、プロトコルサポートの拡張、MQTTの高度な機能強化、およびプラグイン拡張を可能にする強力な管理機能を提供します。これらの管理機能により、サービスを停止することなくシステム設定を動的に調整でき、全体のパフォーマンスと運用の柔軟性を向上させます。主な管理機能は以下の通りです。

- **[クラスター設定](./cluster_settings.md)**：ランタイム中の動的な設定調整をサポートし、MQTT設定、リスナー、ログ記録、モニタリング、クラスターリンクなどのコア設定を含みます。
- **[高度なMQTT](./advanced_mqtt.md)**：トピックリライト、自動サブスクライブ、遅延パブリッシュ、ファイル転送などの機能を簡素化して設定でき、MQTTのユースケースをさらに拡張します。
- **[拡張機能](./extensions.md)**：組み込みの拡張メカニズムとマルチプロトコルゲートウェイのサポートにより柔軟なプロトコル適応を実現し、ユーザー定義のフックやプラグイン開発もサポートします。

EMQXの管理機能は、視覚的なダッシュボードインターフェースを通じて提供され、直感的なユーザー体験により、ユーザーが迅速に利用を開始し、複雑なIoTシナリオの要求に柔軟に対応できるよう支援します。本節では、各モジュールの機能と設定について詳細に説明します。
