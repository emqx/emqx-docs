# Extensions

Extensions機能により、ユーザーはゲートウェイを使って非MQTTプロトコルの接続およびメッセージのパブリッシュ／受信を行い、プラグインやExHookを利用してシステムの修正や拡張が可能です。**Management**をクリックし、下にスクロールして**Extensions**セクションを表示すると、以下が確認できます。

- **Gateways**：すべての非MQTTプロトコルの接続、認証、メッセージの送受信を処理し、それらに対して統一されたユーザーレイヤーのインターフェースと概念を提供します。
- **ExHook**：他の言語を使用してEMQXのシステム機能を修正または拡張する機能を提供します。
- **Plugins**：Erlangで書かれたプラグインをインストールすることでシステム機能を修正または拡張します。

## Gateways

EMQXのマルチプロトコルゲートウェイは、すべての非MQTTプロトコルの接続、認証、メッセージの送受信をサポートします。さまざまなプロトコルに対して統一された概念モデルを提供します。

ゲートウェイページでは、ゲートウェイを有効化し、リスナー設定などの基本設定を行うことができます。EMQXはカスタム設定オプションも提供しています。詳細な設定手順については、以下の一般的なゲートウェイのクイックスタートドキュメントを参照してください。

- [MQTT-SN](../../develop/gateway/mqttsn.md)
- [STOMP](../../develop/gateway/stomp.md)
- [CoAP](../../develop/gateway/coap.md)
- [LwM2M](../../develop/gateway/lwm2m.md)
- [ExProto](../../develop/gateway/exproto.md)

- [OCPP](../../develop/gateway/ocpp.md)
- [GB/T 32960](../../develop/gateway/gbt32960.md)
- [JT/T 808](../../develop/gateway/jt808.md)

ゲートウェイを有効化する前に、適切にセットアップする必要があります。セットアップが完了すると、有効化された各プロトコルゲートウェイの接続数を監視し、**Gateways**ページでゲートウェイの状態（有効化／無効化）を管理できます。

<img src="./assets/gateways.png" alt="画像" style="zoom:67%;" />

::: tip
ゲートウェイを無効化すると、そのゲートウェイに属するすべての接続が切断され、再接続が必要になります。ご注意ください。
:::

### Gateway Setup

Gatewaysページで有効化したいプロトコルゲートウェイを選択し、**Action**列の**Setup**ボタンをクリックします。プロトコルゲートウェイの初期化ページは以下の3ステップで構成されています。

1. 基本設定の構成
2. リスナーの設定
3. 認証の設定

設定項目はプロトコルゲートウェイによって異なります。初期化完了後も、[Gateway Details](#gateway-details)ページから設定項目を更新可能です。

<img src="./assets/gateway-init.png" alt="画像" style="zoom:67%;" />

> Dashboard経由で設定したゲートウェイの設定はクラスター全体に反映されます。

#### Basic Configuration

設定項目はプロトコルゲートウェイごとに異なります。詳細な設定手順は各ゲートウェイのドキュメントを参照してください。

### Gateway Details

プロトコルゲートウェイを有効化すると、**Gateways**ページにリダイレクトされます。ここでゲートウェイの設定管理やカスタマイズが可能です。

- **設定のカスタマイズ**：**Actions**列の**Settings**ボタンをクリックし、ゲートウェイの基本設定、リスナー設定、認証設定を必要に応じて更新できます。
- **接続クライアントの表示**：**Actions**列の**Clients**ボタンをクリックすると、プロトコルゲートウェイ経由でサーバーに接続しているクライアントの一覧が表示されます。クライアントID、ユーザー名、IPアドレス（Clientsページと同様）、状態、接続または登録時間の詳細が含まれます。クライアントを切断する場合は、**Actions**列の**Kick Out**ボタンをクリックしてください。
- **クライアント検索**：クライアントID、ユーザー名、ノードでフィルターをかけて特定のクライアントを素早く検索できます。

## ExHook

フックは特定のイベントポイントでカスタムコードを実行できる一般的な拡張機構です。ExHookは他のプログラミング言語を用いてシステム機能を修正または拡張する機能を提供します。EMQXでサポートされるフック機構により、モジュール関数呼び出し、メッセージ送受信、イベント配信をインターセプトして、システム機能を柔軟に修正・拡張できます。

ExHookページでは、現在追加されているフックの基本情報や状態を確認でき、追加や設定も行えます。

ExHookの定義や開発ガイドラインは[hooks](../extensions/hooks.md)に記載されています。

<img src="./assets/exhook.png" alt="画像" style="zoom:67%;" />

### Add ExHook

ページ右上の**+ Add**ボタンをクリックすると、ExHook追加ページに移動します。追加するExHookの基本情報と接続パラメータを設定し、**Create**をクリックしてデータを送信します。作成に成功すると、ExHook一覧ページにリダイレクトされます。

<img src="./assets/exhook-add.png" alt="画像" style="zoom:67%;" />

### View Details

作成後、ExHook一覧ページでExHook名をクリックすると詳細ページにアクセスできます。詳細ページでは、登録済みフックの総数、成功実行数、失敗実行数、現在の実行率などのExHookメトリクスを確認できます。基本情報の編集後は**Update**ボタンをクリックして保存します。

<img src="./assets/exhook-detail.png" alt="画像" style="zoom:67%;" />

**Registered hooks**タブをクリックすると、現在ExHookで実装されているフックの一覧と、それぞれのパラメータや実行メトリクスを確認できます。

<img src="./assets/exhook-hooks.png" alt="画像" style="zoom:67%;" />

## Plugins

EMQXはプラグインを通じてカスタムビジネスロジックの拡張や、プラグインのプロトコル拡張インターフェースを利用した他プロトコル対応の実装をサポートします。Pluginsページでは、開発済みプラグインパッケージのインストール、起動、保守や設定が可能です。詳細な利用方法は[Plugins](../extensions/plugins.md)を参照してください。

システムプラグインの管理は、左側メニューの**Extensions**内の**Plugins**から行います。

### Plugin List

**Plugins**ページにはインストール済みプラグインの一覧が表示され、プラグイン名、バージョン、作者、実行状態などの詳細が確認できます。特定のプラグインを探す場合は、ページ上部のフィルターで名前や実行状態で検索可能です。

### Install Plugins

詳細な手順は[Install Plugins via Dashboard](../extensions/plugins.md#install-plugins-via-dashboard)を参照してください。

パッケージのインストールに成功するとプラグイン一覧ページにリダイレクトされます。新規インストールされたプラグインはデフォルトで停止状態です。プラグインを有効化するには、該当プラグインの横にある**Start**ボタンをクリックしてください。

### Manage Plugin Execution Order

複数のプラグインがあるシステムでは、実行順序は有効化された順序で決まります。順序の調整は以下の方法で可能です。

- ページ上でプラグインをドラッグ＆ドロップ
- **Actions**列の**More**メニュー内のソートオプションを利用

変更した実行順序は次回ノード再起動後に反映されます。

### Uninstall Plugins

プラグインを削除するには、**Actions**列の**More**メニュー内の**Uninstall**ボタンをクリックしてください。

<img src="./assets/plugins.png" alt="画像" style="zoom:67%;" />

### Plugin Details

プラグイン名をクリックすると詳細ページにアクセスできます。このページでは以下を確認できます。

- **Documentation**：左側パネルにプラグインインストールパッケージ内の`README.md`ファイルが表示されます。
- **Plugin Information**：右側パネルには`release.json`ファイルからのメタデータ（バージョン、作者、その他情報）が表示されます。

プラグインのドキュメントに開発者のウェブサイトリンクが含まれている場合は、右上の**Read More**をクリックしてアクセス可能です。

<img src="./assets/plugin-detail.png" alt="画像" style="zoom:67%;" />
