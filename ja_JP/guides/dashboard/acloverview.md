# アクセス制御

アクセス制御は、クライアントの認証および認可ルールの設定と管理に使用され、特定のクライアントのアクセスを禁止することができます。左側のメニューの**アクセス制御**を展開すると、以下のサブメニューが表示されます。

- **[認証](./authn.md)**：認証機能の作成と設定、認証チェーンの設定、認証パフォーマンス指標の確認などが行えます。
- **[認可](./authz.md)**：認可機能の作成と設定、認可チェーンの設定、認可パフォーマンス指標の確認、認可設定の管理が行えます。
- **禁止されたクライアント**：クライアントIDを禁止することで特定のクライアントのアクセスを禁止します。禁止されたクライアントの作成と管理については、[禁止されたクライアント](../access-control/blacklist.md)を参照してください。
- **フラッピング検出**：禁止されたクライアントに基づき、短期間に頻繁にログインしていると検出されたクライアントを自動的に禁止します。この機能の有効化および設定方法は、ダッシュボードの[フラッピング検出](../access-control/flapping-detect.md)をご覧ください。
