# Extensions

EMQXはネイティブプラグインを超えた複数の拡張機構をサポートしています。本節では、特にフック連携やプロトコル適応パスなど、Erlangコードを直接ブローカーに埋め込まずにEMQXを拡張できる外部拡張インターフェースに焦点を当てます。

## Hooks and Protocol Extensions

EMQXはフック処理およびプロトコル適応のための拡張インターフェースを提供します。これらのインターフェースは、ブローカーのイベントをインターセプトしたり、外部サービスと接続したり、プライベートプロトコルを適応したりする際に、統合の境界を明確に保ちたい場合に適しています。

MQTTおよび非MQTTデバイスアクセスに対しては、EMQXはプロトコルアクセス管理のための統合された[ゲートウェイ](../../develop/gateway/gateway.md)フレームワークも提供しています。

## Multilingual gRPC Extensions

EMQXは[gRPC](https://grpc.io/)を通じて多言語拡張機能を提供し、PythonやJavaなどの言語でサービスを実装し、RPC経由でEMQXと統合することが可能です。

この方法は、フック処理やカスタムTCP/UDPプロトコル解析などのプラグインに類似した機能を実装したいが、実装をブローカーのランタイム外に保持したい場合に有効です。
