# Extensions

EMQXは、ネイティブプラグインを超えた複数の拡張機構をサポートしています。本節では、特にフック統合やプロトコル適応パスといった外部拡張インターフェースに焦点を当て、Erlangコードをブローカーに直接埋め込まずにEMQXを拡張する方法を説明します。

## Hooks and Protocol Extensions

EMQXは、フック処理およびプロトコル適応のための拡張インターフェースを提供しています。これらのインターフェースは、ブローカーのイベントをインターセプトしたり、外部サービスと連携したり、プライベートプロトコルを適応しつつ統合境界を明確に保ちたい場合に適しています。

MQTTおよび非MQTTデバイスのアクセスには、EMQXは統一された[ゲートウェイ](../../develop/gateway/gateway.md)フレームワークも提供しており、プロトコルアクセス管理を行います。

## Multilingual gRPC Extensions

EMQXは、[gRPC](https://grpc.io/)を通じて多言語拡張機能を提供しており、PythonやJavaなどの言語でサービスを実装し、RPC経由でEMQXと統合することが可能です。

この方法は、プラグインと同様の機能（フック処理やカスタムTCP/UDPプロトコル解析など）を実現したいが、実装をブローカーのランタイム外に保持したい場合に有用です。
