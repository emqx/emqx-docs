# APIキー

EMQXダッシュボードの**APIキー**ページでは、[HTTP API](../guides/api.md)リクエストの認証に使用するAPIキーとシークレットキーを生成できます。

## APIキーの作成

1. ダッシュボードで**システム** -> **APIキー**に移動します。

2. 右上の**+ 作成**ボタンをクリックして、APIキー作成ダイアログを開きます。

3. APIキーの詳細を設定します：

   - **Expire At**フィールドを空欄にすると、キーは期限切れになりません。
   - （EMQX Enterpriseのみ）APIキーに割り当てるロールを選択できます。利用可能なロールの詳細は[ロールと権限](../guides/api.md#roles-and-permissions)をご参照ください。

4. **確認**をクリックします。APIキーとシークレットキーが**作成成功**ダイアログに表示されます。

   ::: warning 重要なお知らせ

   APIキーとシークレットキーは必ず安全な場所に保存してください。このダイアログを閉じるとシークレットキーは再表示されません。

   :::

5. **閉じる**をクリックしてダイアログを閉じます。

## APIキーの管理

APIキーを作成した後は、APIキー一覧ページから管理できます：

- **詳細表示**：**名前**列のキー名をクリックします。
- **編集**：**操作**列の**編集**ボタンをクリックして、有効期限のリセット、有効状態の変更、メモの更新が可能です。
- **削除**：**操作**列の**削除**ボタンをクリックして、不要になったAPIキーを削除できます。
