# APIキー

EMQXダッシュボードの**APIキー**ページでは、[HTTP API](../guides/api.md)リクエストの認証に使用するAPIキーとシークレットキーを生成できます。

## APIキーの作成

1. ダッシュボードで**システム** -> **APIキー**に移動します。

2. 右上の**+ 作成**ボタンをクリックして、APIキー作成ダイアログを開きます。

3. APIキーの詳細を設定します：

   - キーの有効期限を設定しない場合は、**Expire At**フィールドを空欄のままにします。
   - （EMQX Enterpriseのみ）APIキーに割り当てるロールを任意で選択します。利用可能なロールの詳細は[ロールと権限](../guides/api.md#roles-and-permissions)をご参照ください。

4. **確認**をクリックします。APIキーとシークレットキーが**作成成功**ダイアログに表示されます。

   ::: warning 重要なお知らせ

   APIキーとシークレットキーは必ず安全な場所にすぐ保存してください。このダイアログを閉じるとシークレットキーは再表示されません。

   :::

5. **閉じる**をクリックしてダイアログを閉じます。

## APIキーの管理

APIキー作成後は、APIキー一覧ページから以下の操作が可能です：

- **詳細表示**：**Name**列のキー名をクリックします。
- **編集**：**Actions**列の**編集**ボタンをクリックし、有効期限のリセット、有効状態の変更、メモの更新ができます。
- **削除**：不要になったAPIキーは**Actions**列の**削除**ボタンで削除できます。
