# ネームスペースの設定と管理

ネームスペースは、ダッシュボードまたはREST APIを使用して設定および管理できます。

### ダッシュボードでのネームスペース削除

ネームスペースを削除するには、**Actions**列の**Delete**をクリックします。確認後、ネームスペースは完全に削除されます。

::: tip 注意

ネームスペースを削除する前に、そのネームスペースに関連付けられたすべてのアクティブなクライアントが適切に切断されていることを確認してください。

:::

### REST APIによるネームスペース一覧取得

<<<<<<< HEAD
EMQXは、必要に応じてネームスペースの詳細一覧を取得できる2つのエンドポイントを提供しています。

| エンドポイント | 範囲 | 設定含むか |
| -------------- | ---- | ---------- |
| `GET /mt/ns_list_details` | すべてのネームスペース（自動作成および明示的作成） | いいえ |

| パラメータ | 型 | デフォルト | 説明 |
| ---------- | -- | ---------- | ---- |
| `last_ns` | 文字列 | `""` | ページネーション用カーソル。前ページの最後のアイテムの `name` を渡すと次ページを取得。 |
| `limit` | 整数 | `100` | 1ページあたりの最大ネームスペース数。 |

::: tip 重要なお知らせ

クライアントがネームスペースを明示的に作成する前に接続すると、後から適用されるレートリミッターなどの設定は継承されません。新しい設定を強制するには、これらのクライアントを手動で切断し、再接続させる必要があります。

      "bytes": {
        "rate": "20MB/10s",
        "burst": "300MB/1m"

        "burst": "60/30s"
      }
    }

  "session": {
    "max_sessions": 100
  }
