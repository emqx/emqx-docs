# Developer Guides

Developer Guidesは、クライアントをEMQXに接続し、MQTTデータを処理し、外部システムと統合し、高度なEMQX機能を利用するための開発者向けガイドです。本章の主な内容は以下の通りです。

- [Client SDK](./connect-emqx/introduction.md) は、C、Java、Go、Python、JavaScriptのMQTTクライアントでEMQXに接続するためのSDK例を提供します。

- [Use curl with EMQX](./connect-emqx/curl.md) は、コマンドラインからMQTTトピックのパブリッシュおよびサブスクライブを行う方法を示します。

- [Use Node-RED with EMQX](./connect-emqx/node-red.md) は、Node-REDをEMQXに接続し、MQTTメッセージのフローを構築する方法を説明します。

- [Tutorials](./tutorial/tutorial.md) は、MQTTプログラミングや一般的なEMQX開発シナリオの実践的なガイドを提供します。

- [Rule Engine](./data-integration/rules.md) は、IoTデータをリアルタイムに抽出、フィルタリング、強化、変換するための組み込みデータ処理エンジンを紹介し、データ統合と連携して動作します。

- [Smart Data Hub](./data-integration/smart-data-hub.md) は、スキーマ管理、データ検証、MQTTメッセージのリアルタイム変換を一元的に行うソリューションを提供します。

- [Data Integration](./data-integration/data-bridges.md) は、SinkおよびSourceコンポーネントを使って、EMQXをデータベース、メッセージキュー、クラウドサービスなどの外部データシステムと接続する方法を解説します。

- [Flow Designer](./flow-designer/introduction.md)（EMQX Enterprise機能）は、ルール、アクション、統合をグラフィカルインターフェースで接続し、ノーコードでデータ処理パイプラインを構築するビジュアルツールです。

- [Advanced Features](./advanced-features.md) は、メッセージキュー、MQTT over WebSocket、MQTT over QUIC、クラスターリンク、MQTTによるファイル転送、マルチプロトコルゲートウェイ、クライアント属性などの高度な機能を紹介します。

- [EMQX AI](./emqx-ai/overview.md) は、MQTT上のMCP、MCPブリッジ、SDK、リアルタイム音声・映像AIサービスなどのAI関連機能を紹介します。

- [Architecture](./architecture-introduction.md) は、EMQXのクラスタリング、耐久性ストレージ、インフライトウィンドウとメッセージキュー、メッセージ再送機能について解説します。

- [MQTT Reference](./mqtt-reference.md) は、MQTTプロトコルのバージョン、用語、機能、リースンコードのリファレンス情報を提供します。
