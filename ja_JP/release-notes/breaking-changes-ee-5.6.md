# EMQX 5.6 における非互換変更点

## e5.6.0

- [#12576](https://github.com/emqx/emqx/pull/12576) 5.6 以降、「設定マニュアル」ドキュメントから `bridges` 設定ルートが削除されます。

  `bridge` は現在、送信側のデータ統合には `action` + `connector`、受信側のデータ統合には `source` + `connector` として扱われます。
  なお、`bridges` 設定（`cluster.hocon` 内）および REST API パス `api/v5/bridges` は引き続き動作しますが、非推奨とされています。

- [#12634](https://github.com/emqx/emqx/pull/12634) HOCON 設定ファイル内の三重引用符（triple-quote）文字列値は、エスケープシーケンスをサポートしなくなりました。

  詳細は[こちらのプルリクエスト](https://github.com/emqx/hocon/pull/290)をご参照ください。
  EMQX ユーザーへの影響の概要は以下の通りです：

  - EMQX 5.6 は `cluster.hocon` に三重引用符文字列を生成する初のバージョンであり、生成された設定ファイルに関しては互換性の問題はありません。
  - ユーザーが手動で作成した設定ファイル（例：`emqx.conf`）については、`\n`、`\r`、`\t`、`\\` などのエスケープシーケンスが使用されていないかを十分に確認する必要があります。
    使用されている場合は、三重引用符ではなく通常の引用符（`"` 一対）に変更してください。
