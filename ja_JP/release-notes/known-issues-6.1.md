# EMQX 6.1 の既知の問題

## 6.1.1

| バージョン | 問題                                                         | 回避策                                                        | 状態   |
| ----------- | ------------------------------------------------------------ | ------------------------------------------------------------ | ------ |
| 5.8.0       | **Durable Storage が有効な場合、コア・レプリカントクラスターの起動が完了しない可能性があります**<br />コアノードとレプリカントノードでクラスターを初期化する際、Durable Storage（DS）のメタデータがノード間で不整合になることがあり、Durable Sessions、キュー、またはストリームの関連機能が部分的に利用不可になる場合があります。これは新規クラスターだけでなく、EMQX 5.x からアップグレードしたクラスターにも影響し、特に `n_sites > 1` の場合に発生しやすいです。通常、以下のような継続的な警告で示されます。<br />`msg: dsrepl_optimistic_leader_fail, reason: {init_failed,{error,recoverable,{fsm_needs_upgrade,0}}}` | レプリカントノードを1台ずつ停止して再起動してください。 |        |
