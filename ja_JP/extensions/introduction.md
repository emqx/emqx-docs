# Extensions

EMQXはネイティブプラグインを超えた複数の拡張機構をサポートしています。本節では、特にフック連携やプロトコル適応パスなど、Erlangコードを直接ブローカーに組み込まずにEMQXを拡張できる外部拡張インターフェースに焦点を当てます。

## Hooks and Protocol Extensions

EMQXはフック処理およびプロトコル適応のための拡張インターフェースを提供しています。これらのインターフェースは、ブローカーのイベントをインターセプトしたり、外部サービスと連携したり、プライベートプロトコルを適応したりする際に、統合の境界を明確に保ちながら利用するのに適しています。

MQTTおよび非MQTTデバイスのアクセスには、EMQXは統一された[ゲートウェイ](../gateway/gateway.md)フレームワークも提供しており、プロトコルアクセス管理を行うことができます。

## Multilingual gRPC Extensions

EMQXは[gRPC](https://grpc.io/)を通じて多言語対応の拡張機能を提供しており、PythonやJavaなどの言語でサービスを実装し、RPC経由でEMQXと統合することが可能です。

この方法は、フック処理やカスタムTCP/UDPプロトコル解析など、プラグインに類似した機能を実現したいが、実装をブローカーのランタイム外に置きたい場合に有効です。
