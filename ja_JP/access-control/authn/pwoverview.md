# パスワード認証

EMQXは、最もシンプルで一般的なパスワード認証をサポートしており、クライアントがユーザー名、クライアントID、および対応するパスワードなど、IDを示す資格情報を提供する必要があります。

組み込みデータベースに加えて、EMQXはパスワード認証のためにさまざまなバックエンドデータベースとの統合もサポートしています。詳細は以下のリンクをご参照ください。
